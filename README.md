# Eurin Hash — Digital Hub

The personal portfolio and technology hub of Eurin Hash.

## Stack
Next.js 15 · React 19 · TypeScript · Tailwind CSS

## Routes
/ · /about · /work · /work/[slug] · /architecture · /labs · /ecosystem · /journal · /community · /services · /contact

## Development
```bash
npm install
npm run dev
```

Production build:
```bash
npm run build
npm start
```

## Direction
This is not a conventional CV website. The interface is designed as a premium digital hub presenting projects, architecture thinking, experiments, writing and the wider technology ecosystem.

Production domain: https://hub.eurinhash.com
